my friend runs a physiotherapy center.
he has 5-6 employees
he has more than 60 regular patients
he is supposed to tell the staff about the treatment on daily basis
and they are supposed to mark the entry whenever patient visits, so that they can bill accordingly in the month end or weekly
they can mark the fees paid 
    - daily, weekly, monthly or select multiple days, weeks (unselect few) and then mark it paid.

user roles
    - Admin
    - HOD
    - staff


Everything will run on a PWA and would sync with google drive folder set by admin.
Admin and everyone will download the app
One user will create healthcare facility
Will name it
Will set a logo (optional)

Then will show the QR code or would give a invitation code to join the facility.
QR and invitation code would be generated by selecting the role. but admin can change the role later too.


v0 functions
Admin or HOD would add a patient
    - Name, Age, phone number, gender, address (optional)
Staff, HOD or Admin will mark the attendance and would select the date, time is optional
Admin or HOD will mark the fees paid

Google Drive is deferred by v0.1

Use minimalist design with flat icons, don't use emoji in icons or inside code.

You can take the inspiration of design and tech stack from suno app.
